# Demo samples

Fictional texts to paste into Airlock (web, iPhone/Mac, Android). **Every name, address, number and organisation here is invented.** Phone numbers use the 555 range, emails use `example.com`/`example.org`, and IDs are made up.

| File | Try it with | What to look for |
|------|-------------|------------------|
| `01-landlord.txt` | Draft a reply | Names, address and phone become chips; the employer is generalised; the reply comes back with real names |
| `02-lease-clause.txt` | Explain simply | A quick task that can be answered on the device — nothing leaves |
| `03-hospital-bill.txt` | Questions to ask | Account and claim numbers sealed; health details protected |
| `04-hr-complaint.txt` | Help me with this | Colleagues' names and the employer sealed; red-team flags what's still identifying |
| `05-school-absence.txt` | Draft a reply | A child's name, a school and a clinic in one message |
| `06-scam-text.txt` | Is this a scam? (Proof) | Urgency, payment pressure and a look-alike link |
| `07-phishing-email.txt` | Is this a scam? (Proof) | Fake bank, spoofed sender, credential request |
| `08-family-chat.txt` | Summarise | Several people with nicknames — coreference keeps "Bea" and "Beatrice" the same person |

Tip: add "Raj Patel" (landlord) and your own fictional name to the Vault first — Vault names are caught even when the on-device model misses them.
