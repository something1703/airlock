## 3. Decision log

| Date | Decision | Alternatives considered | Why |
|------|----------|------------------------|-----|
| 18 Nov | **Merger: a contact / ID / secret pattern hit wins over any other-category detection strictly inside it** (all three engines + fixtures `merge.json`, `seal.json`). A Vault name inside the user's own email ("maya" in maya.chen@example.net) used to outrank the email pattern, giving `[[PERSON_ME]].chen@…`, which the gate blocked — 52.5% of `F_vault` mock documents couldn't be sent. After: 10.8% blocked, completed answers 47.5% → 89.2%. The mock doc-leak rate rose (14.2% → 30.0%) only because previously-blocked documents now go out and the mock detector's deliberate misses become visible; no leaked value comes from an email (checked) | Leave as is (fails closed); special-case emails only | Found by AirlockBench; the name inside an address is part of the address, and the whole address is sealed |
| 18 Nov | **AirlockBench (WP-22) runs on the TypeScript engine as a Node CLI (`web/bench/`), scored by Python (`eval/scorer/`).** Datasets come from a deterministic template generator (`synth-tpl.v1`, same schema as `synth.v1`); bulk JSONL is regenerated, only hashes (`eval/datasets/MANIFEST.json`) and the 5-item demo set are committed. Every run so far is **mock** (oracle on-device model, scripted answers/judge/attacker); live runs (Firebase AI Logic, GCS, SDP, BigQuery) are built and fake-tested but refuse to start without `--live --i-have-permission` **and** `AIRLOCK_BENCH_LIVE_OK=yes`, and happen last on the separate eval project with the owner's permission. `C_rules_nl` is skipped (no NL tagger outside Swift) | A Swift `Bench/AirlockBench` macOS app as in docs/07 §2 | The TS engine is byte-compatible with Swift/Kotlin via `spec/fixtures`, runs in CI in seconds, and needs no Apple hardware for the mock path.
